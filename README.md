# 📊Финансов Мениджър📊

## Описание на проекта
**Финансов Мениджър** е конзолно приложение, което позволява на потребителя да управлява личните си финанси. С него може:
- да се създаде финансов профил
- да се въвеждат доходи и разходи за конкретен месец
- да се визуализират отчети
- да се визуализират диаграми
- да се правят прогнози
- да се извеждат месеци по различни критерии

Програмата е предназначена за единични потребители, които искат бързо, лесно и удобно да следят финансите си през годината.
